#### Основные понятия сетей

- **<span style="color:rgb(0, 240, 180)">Сеть</span>** — совокупность устройств, соединенных между собой для обмена данными.
    
- **<span style="color:rgb(0, 240, 180)">Узел (Node)</span>** — любое устройство в сети (компьютер, принтер, маршрутизатор).
    
- **<span style="color:rgb(0, 240, 180)">Сетевой интерфейс</span>** — точка подключения устройства к сети (например, Ethernet-порт).
    
- **<span style="color:rgb(0, 240, 180)">Протокол</span>** — набор правил и стандартов для обмена данными (например, TCP/IP, HTTP).
    

#### 2. Типы сетей

- **LAN (Local Area Network)** — локальная сеть, ограниченная небольшим пространством (офис, дом).
    
- **WAN (Wide Area Network)** — глобальная сеть, соединяющая устройства на большом расстоянии (Интернет).
    
- **MAN (Metropolitan Area Network)** — сеть в пределах города.
    
- **VPN (Virtual Private Network)** — виртуальная частная сеть, обеспечивающая безопасное соединение через публичные сети.
    

#### 3. Модель OSI

- **7 уровней модели OSI**:
    
    1. **Физический (Physical)** — передача битов по кабелю или беспроводной связи.
        
    2. **Канальный (Data Link)** — управление доступом к среде передачи (MAC-адреса).
        
    3. **Сетевой (Network)** — маршрутизация и логическая адресация (IP-адреса).
        
    4. **Транспортный (Transport)** — обеспечение надежной передачи данных (TCP, UDP).
        
    5. **Сеансовый (Session)** — управление сессиями между устройствами.
        
    6. **Представительский (Presentation)** — преобразование данных (шифрование, сжатие).
        
    7. **Прикладной (Application)** — взаимодействие с пользователем (HTTP, FTP, SMTP).
        

#### 4. IP-адресация

- **IP-адрес** — уникальный идентификатор устройства в сети (IPv4: 32 бита, IPv6: 128 бит).
    
- **Маска подсети** — определяет, какая часть IP-адреса относится к сети, а какая — к устройству.
    
- **Классы IP-адресов**:
    
    - Класс A: 1.0.0.0 — 126.0.0.0 (большие сети).
        
    - Класс B: 128.0.0.0 — 191.255.0.0 (средние сети).
        
    - Класс C: 192.0.0.0 — 223.255.255.0 (малые сети).
        
- **NAT (Network Address Translation)** — преобразование частных IP-адресов в публичные.
    

#### 5. Маршрутизация

- **Маршрутизатор (Router)** — устройство, которое пересылает пакеты между сетями.
    
- **Таблица маршрутизации** — список правил, по которым маршрутизатор определяет, куда отправлять пакеты.
    
- **Протоколы маршрутизации**:
    
    - **Статическая маршрутизация** — маршруты задаются вручную.
        
    - **Динамическая маршрутизация** — маршруты обновляются автоматически (RIP, OSPF, BGP).
        
- **Метрика** — параметр, используемый для выбора наилучшего маршрута (например, количество переходов).
    


#### 6. Протоколы передачи данных

- <span style="color:rgb(0, 240, 180)">**TCP (Transmission Control Protocol)**</span> — надежный протокол с установлением соединения.
    
- <span style="color:rgb(0, 240, 180)">**UDP (User Datagram Protocol)**</span> — менее надежный, но более быстрый протокол без установления соединения.
    
- <span style="color:rgb(0, 240, 180)">**ICMP (Internet Control Message Protocol)**</span> — используется для диагностики сети (ping, traceroute).

#### 7. Безопасность в сетях

- **Firewall (Межсетевой экран)** — фильтрует трафик между сетями.
    
- **VPN (Virtual Private Network)** — обеспечивает безопасное соединение через публичные сети.
    
- **Шифрование** — защита данных от несанкционированного доступа (SSL/TLS).
    

#### 8. Основные команды для диагностики сетей

- **ping** — проверка доступности узла.
    
- **traceroute (tracert)** — определение пути пакета до узла.
    
- **ipconfig (ifconfig)** — информация о сетевых интерфейсах.
    
- **netstat** — статистика сетевых соединений.
    
- **nslookup** — запрос DNS-сервера для получения IP-адреса по доменному имени.
    

#### 9. Сетевые устройства

- **Коммутатор (Switch)** — устройство для соединения устройств в локальной сети.
    
- **Маршрутизатор (Router)** — устройство для соединения разных сетей.
    
- **Хаб (Hub)** — устаревшее устройство для соединения устройств в сети (работает на физическом уровне).
    
- **Мост (Bridge)** — устройство для соединения сегментов сети.
    

#### 10. Беспроводные сети (Wi-Fi)

- **SSID (Service Set Identifier)** — имя беспроводной сети.
    
- **Шифрование** — WEP, WPA, WPA2, WPA3 для защиты данных.
    
- **Каналы** — частотные диапазоны для передачи данных (2.4 ГГц, 5 ГГц).
